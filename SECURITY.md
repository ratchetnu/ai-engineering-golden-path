# Security

This is a reference project with no hosted service and no user data.

If you find a security problem in the code or the CI configuration, please use
GitHub's **private vulnerability reporting** (Security tab → "Report a
vulnerability") rather than opening a public issue.

If you accidentally commit a credential: treat it as leaked. Revoke or rotate
it first, then remove it from the code. Removing it from history alone is not
enough, because forks and caches may already have it.
